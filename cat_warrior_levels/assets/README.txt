Put the character portraits here:

    jacob.png    (the blue-and-gold armored tabby with blue eyes)
    isaac.png    (the orange tabby in silver-blue plate)

Square images work best. Roughly 400x400 or larger.

The app uses these automatically if they exist. If they are missing it draws its own
SVG cat warrior instead, so nothing breaks either way.

.jpg, .jpeg, .webp and .gif also work -- if you use a different extension, update the
matching `portrait:` path in the CHARACTERS block at the top of the script in
cat-warrior-levels.html.
